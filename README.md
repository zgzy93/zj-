# 刷题台

三门课合一的本地刷题页面。**单文件、零依赖、离线可用**，双击 `index.html` 就能用。

## 内容

| 科目 | 题数 | 章节 |
|---|---|---|
| 单片机原理与接口技术 | 594 | 8 |
| 操作系统原理 | 321 | 6 |
| Python程序设计 | 184 | 2 |
| **合计** | **1099** | **16** |

答案来源：

- 单片机、操作系统：学习通批改页面给出的**官方正确答案**
- Python：程序阅读填空题是官方答案；综合作业没有官方答案，为逐题作答并经 Python 实跑核对

## 功能

- 六种模式：章节 / 全部 / 随机 / 错题 / 收藏 / 题库
- 题型筛选（单选、判断、填空、计算、简答、综合）
- 答题即判：选择题点选、填空题回车、简答题展开参考答案
- 错题本自动收录、收藏、进度按科目独立保存（localStorage）
- 键盘快捷键：`←` `→` 翻题、`1`–`4` 选项、`Enter` 确认、`S` 收藏、`R` 随机、`Space` 看答案
- 昼夜主题切换，记住上次的选择
- 移动端适配

## 目录

```

```
